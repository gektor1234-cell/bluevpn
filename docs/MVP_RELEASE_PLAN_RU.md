# BlueVPN MVP Release Plan

Цель: продаваемый Windows MVP, который можно установить одним `.exe`, зарегистрироваться, оплатить тариф и пользоваться рабочим VPN без ручных действий.

## Что уже должно оставаться неприкосновенным

- Рабочий туннель: `BlueVPNDev1`.
- Dev-сервер: `37.220.85.211`.
- WireGuard connect/disconnect, social-only и server-issued config не переписываем без прямой причины.
- Старые рабочие конфиги и ключи не удаляем ради косметики.

## Ближайший маршрут

1. Закрепить Windows-first UX.
   - Десктопный стартовый размер окна.
   - Более коммерческий визуальный стиль.
   - Нормальные состояния кнопок: загрузка, cooldown, ошибки понятным текстом.

2. Довести оплату до боевого сценария.
   - YooKassa в production-режиме через переменные окружения.
   - Создание заказа из приложения.
   - Редирект на оплату.
   - Webhook подтверждает оплату и активирует тариф.
   - Без webhook тариф нельзя получить бесплатно.

3. Ввести тарифные ограничения после оплаты.
   - Количество устройств.
   - Набор соцсетей / приложений.
   - Traffic pack / unlimited.
   - Срок действия подписки.

4. Подготовить безопасность MVP.
   - Не хранить пароли в открытом виде.
   - Не показывать пользователю WireGuard-конфиги.
   - Сохранять чувствительное состояние в защищенной зоне.
   - Не ломать shared config ACL для нормального/elevated запуска.

5. Подготовить распространение.
   - Один установщик `.exe`.
   - Ярлык на рабочем столе и в меню Пуск.
   - Проверка обновления/версии.
   - Документация: как установить, как оплатить, как диагностировать.

6. После Windows MVP.
   - Android-версия.
   - Масштабирование backend.
   - Админ-панель для пользователей, устройств, заказов и подписок.

## Текущий фокус

Не расширять платформы и не строить красивую архитектуру раньше времени. Каждый шаг должен приближать к сценарию:

пользователь скачал установщик -> установил -> зарегистрировался -> оплатил -> нажал подключить -> VPN работает.
