После каждого стабильного этапа:

- коротко обновить `CURRENT_HANDOFF.md`;
- коротко обновить `RELEASE_STATE.md`;
- при необходимости обновить `CODEX_CONTEXT_COMPACT_RU.md`;
- если контекст снова станет тяжелым, создать новый `NEW_CHAT_HANDOFF_YYYY_MM_DD`.
