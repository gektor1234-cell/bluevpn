# Green VPN: закрытая paid beta-страница

Дата: 2026-07-10. Статус: подготовлено и проверено локально, не опубликовано. Основной сайт, production downloads, stable-клиенты и production API не изменены.

## Состав

- Статический пакет: `paid_beta_site`.
- Главная beta: `/paid-beta/`.
- Условия участия: `/paid-beta/terms/`.
- Дополнение о данных: `/paid-beta/privacy/`.
- Android: `/paid-beta/downloads/GreenVPN_Android.apk`.
- Windows: `/paid-beta/downloads/GreenVPN_Setup.exe`.
- Контрольные суммы: `/paid-beta/downloads/manifest.json`.

В репозитории намеренно нет файлов из каталога `downloads`: они должны копироваться только из финальной marker-gated сборки этапа 7. Публичные stable-файлы и их manifests при этом не заменяются.

## Защита от случайной публикации

- Все HTML-страницы содержат `noindex,nofollow,noarchive,nosnippet`.
- `robots.txt` запрещает обход всего тестового пути.
- При развёртывании Nginx должен дополнительно вернуть `X-Robots-Tag: noindex, nofollow, noarchive`.
- Directory listing должен быть выключен.
- Пакет нельзя размещать вместо `public_demo_site` или production `/downloads/`.
- Публикация разрешена только вместе с отдельным `/paid-beta-api`, после сборки downloads и smoke обоих тестовых узлов.

## Фактические условия на странице

- Доступ только по персональному инвайту.
- Trial: 3 дня.
- Первый оплачиваемый период: 149 RUB за 30 дней.
- Следующие периоды: 299 RUB за 30 дней.
- Не более двух устройств.
- Реклама и автопродление выключены.
- Нет обещаний фиксированной скорости, выделенного IP или доступности любого стороннего сервиса.
- Для неподписанного Windows installer показано предупреждение не отключать системную защиту.

## Проверка

- Desktop viewport 1280x720: без горизонтального overflow и наложений.
- Mobile viewport 390x844: без горизонтального overflow и наложений во всех секциях.
- Главная, условия и privacy открываются по относительным путям.
- Иконка приложения загружается из фактического Android launcher asset.
- HTML parser проверил три страницы, локальные ссылки, ресурсы, anchors, duplicate IDs и robots meta: 0 ошибок.
- Отсутствуют только три ожидаемых release-файла, создаваемых на этапе 7.

Тексты условий и дополнения о данных описывают реализованное поведение beta, но не являются заключением профильного юриста. Юридическая проверка остаётся обязательным действием владельца перед выходом за пределы закрытой тестовой группы.
