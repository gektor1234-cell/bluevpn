- Ожидаемая сумма по скрину кабинета: `1 288 ₽/мес`.
- Статус: активно, нужно держать оплаченным, иначе ломается почта и admin email 2FA.

### 2. Timeweb Cloud `Friendly Cetus`

- Для чего: публичный сайт, admin site, `api.greenvpn.pro` reverse proxy, SMTP relay для Yandex 360.
- IP: `72.56.32.197`
- Кабинет: `https://timeweb.cloud/`
- DNS:
  - `greenvpn.pro -> 72.56.32.197`
  - `www.greenvpn.pro -> 72.56.32.197`
  - `api.greenvpn.pro -> 72.56.32.197`
  - `admin.greenvpn.pro -> 72.56.32.197`

- Ориентир:

  - если включен backup из расчетного экрана: примерно `1 480 ₽/мес`.

- Статус: production подключена, деньги можно принимать технически, но массовый запуск ждет подписанный installer.

### 7. SMS.ru

- Для чего: SMS/phone auth.
- Кабинет: `https://sms.ru/`

- Статус: backend сообщает `smsProductionReady=true`, значит сервисный контур включен. Для бюджета считать как переменный расход на SMS.

## Будущие расходы перед публичной рекламой

### 11. Code Signing / подпись Windows-приложения

- Для чего: убрать `Unknown Publisher`, подписывать `greenvpn.exe`, `greenvpn_service.exe`, DLL и installer.
- Это не SSL-сертификат, а отдельный Code Signing certificate или Microsoft Trusted Signing.
- Период: обычно ежегодно или подписка у провайдера.
- Сумма: неизвестно до выбора поставщика; ожидать как заметную отдельную покупку.
- Бюджетное решение от 2026-05-11: сейчас не покупать. Проект сначала должен окупить текущие регулярные расходы и дать прибыль, которая покрывает покупку Code Signing сверху. Только после этого возвращаться к покупке подписи.
- Статус: отложено владельцем до окупаемости. Для холодной массовой рекламы это остается правильным trust-шагом, но не входит в текущий оплачиваемый стартовый бюджет.

### 12. External monitoring probe

- Для чего: отдельная внешняя проверка API/VPN/платежей, чтобы видеть проблемы не только с основного сервера.
- Вариант: маленький VPS у отдельного провайдера.
- Сумма: неизвестно; ориентир `300-1 000 ₽/мес`, если брать минимальный VPS.
- Статус: желательно перед рекламой. Если бюджет ограничен, можно сначала использовать уже установленный probe на `72.56.32.197`, а отдельный внешний VPS добавить позже.

### 13. Дополнительные VPN-ноды

- Для чего: масштабирование, fallback, антиблокировка, разгрузка.
- Текущий статус: первый дополнительный VPN-узел уже куплен и поднят как скрытый draft (`5.129.216.42`). Следующие узлы не покупать заранее без метрик.
- Ориентиры из бизнес-стратегии:
  - NL 200 Мбит/с: около `2 090 ₽/мес`;
  - NL 1 Гбит/с: около `3 890-4 030 ₽/мес`;
  - Frankfurt/Almaty варианты: около `3 240-5 420 ₽/мес`.
- Статус: следующий узел покупать после первых пользователей и метрик либо при устойчивой красной/желтой нагрузке.

## Предстартовое напоминание: что пополнить перед рекламой

Перед тем как включать публичную рекламу, пройти этот список в один заход. Это именно список "куда зайти и что проверить/пополнить", чтобы запуск не умер из-за нулевого баланса или просроченной подписки.

| Приоритет | Куда зайти | Что сделать | Почему важно |
|---|---|---|---|
| Критично | Timeweb Cloud | Проверить баланс/автосписание для `37.220.85.211`, `72.56.32.197` и `5.129.216.42`, положить запас минимум на 1 месяц | Если отключат, упадут сайт, API reverse proxy, admin, SMTP relay или VPN-узлы |
| Критично | REG.RU | Проверить дату продления `greenvpn.pro`, включить автопродление или оплатить заранее | Без домена ломаются сайт, API, почта, оплата и `nl1.vpn.greenvpn.pro` |
| Критично | Яндекс 360 | Проверить баланс/автоплатеж и что почта Green VPN не будет отключена | Почта нужна для support, no-reply, admin email 2FA и доверия |
| Критично | SMS.ru | Проверить баланс и пополнить перед рекламой | Без SMS пользователи могут не пройти phone auth/подтверждение, если включен телефонный сценарий |
| Критично | YooKassa | Проверить, что магазин активен, выплаты/карта/самозанятый статус в порядке, webhook не отключен | Иначе пользователи могут оплатить, а деньги/активация/чеки пойдут с проблемами |
| Отложено | Code Signing provider | Сейчас не покупать; вернуться после окупаемости и прибыли | Без подписи cold-аудитория может сильнее пугаться предупреждений Windows/браузеров, но покупка не входит в текущий бюджет |
| Желательно | Telegram bot/admin alerts | Создать bot/chat и применить token/chat id через server-only env | Чтобы сразу видеть падения и ошибки оплаты |
| Желательно | External monitoring VPS | Купить маленький отдельный VPS или назначить probe host | Чтобы мониторинг видел проблемы снаружи, не только с основного сервера |
| Желательно | GitHub/backup | Проверить, что код/артефакты не завязаны только на один ПК | Чтобы не потерять проект при проблеме с машиной |

Минимальные суммы-запасы перед рекламой:

- SMS.ru: пополнить хотя бы на тестовый запас SMS для первых пользователей. Точную сумму брать из тарифа SMS.ru; если нет понимания, положить небольшой стартовый баланс и смотреть расход.
- Timeweb Cloud: держать запас минимум на 1 месяц работы проектных серверов, сейчас ориентир около `6 620 ₽/мес` без личного `Friendly Linnet`.
- Яндекс 360: проверить, что ближайшее списание `1 288 ₽` пройдет.
- REG.RU: домен оплатить заранее, не ждать последнего дня.
- YooKassa: проверить не баланс, а статус магазина, реквизиты выплат, webhook и доступ к кабинету.
- Code Signing: сейчас не оплачивать. Возвращаемся к нему только когда проект отбил текущие расходы и покупка подписи не уводит общий результат в минус.

Правило запуска: если хотя бы один критичный пункт выше красный или непонятный, публичную рекламу не включать. Сначала оплатить/проверить сервис, затем делать финальный smoke. Code Signing по текущему бизнес-решению не считается расходом текущего запуска; это отдельная инвестиция после окупаемости.
