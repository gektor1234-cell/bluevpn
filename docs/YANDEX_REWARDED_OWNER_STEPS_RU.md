# Green VPN: что владельцу сделать для настоящей rewarded-рекламы

Этот чеклист описывает только ручные действия в кабинетах. Кодовая подготовка уже сделана: Android умеет работать с Yandex rewarded SDK за feature flag, Windows остаётся на web-gate.

## Шаги в Яндексе

1. Открой сайт `https://ads.yandex.com/`.
2. Войди в Яндекс ID, который будет владельцем рекламного дохода.
3. Открой партнёрскую часть Рекламной сети Яндекса.
4. Выбери формат работы и выплат: самозанятый, ИП или юрлицо.
5. Заполни реквизиты для выплат.
6. Добавь Android-приложение Green VPN как площадку/приложение для монетизации.
7. В описании не используй формулировки про обход блокировок. Безопасный тон: защищённое подключение, приватность, шифрованный VPN-туннель, безопасный доступ в публичных сетях.
8. Дождись модерации приложения или доступности создания рекламного блока.
9. Создай рекламный блок формата rewarded / rewarded video.
10. Скопируй `adUnitId` этого rewarded-блока.
11. Передай мне только `adUnitId`. Пароли, API-ключи, платёжные реквизиты и доступ к кабинету не нужны.

## Что я делаю после `adUnitId`

1. Добавляю `adUnitId` в server-only env или в release build define.
2. Собираю отдельный Android preview APK с включённым `GREENVPN_YANDEX_REWARDED_ADS_ENABLED=true`.
3. Проверяю, что приложение показывает настоящую rewarded-рекламу и backend засчитывает grant только после reward-события.
4. Публикую отдельный preview APK, не заменяя стабильный основной APK без отдельного решения.
5. Даю ссылку на тест 5-10 пользователям.

## Важно

- Не просить пользователей кликать по рекламе.
- Не обещать доступ к заблокированным ресурсам.
- Не делать рекламу единственным смыслом приложения: Green VPN должен выглядеть и работать как полноценный VPN-сервис.
- Windows-реклама будет отдельной web-gate историей: РСЯ web-блок или прямая реклама, не мобильный rewarded SDK.
