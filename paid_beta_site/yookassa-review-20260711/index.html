Green VPN: управление автопродлением

Материалы для проверки сценария сохранения и самостоятельного отключения способа оплаты.

Пользователь управляет автопродлением самостоятельно

Переключатель расположен на экране тарифа Android-приложения. Пользователь может отключить автопродление без обращения в поддержку.

Полноэкранные скриншоты с URL подключённого сайта

  • Автопродление включено
  • Автопродление отключено

Что выполняет отключение

  • приложение отправляет авторизованный запрос POST /api/v1/subscription/auto-renew/cancel;
  • сервер устанавливает признак автопродления в выключенное состояние;
  • сервер удаляет привязку сохранённого способа оплаты из подписки;
  • уже оплаченный период продолжает действовать, новые автоматические списания не создаются.
