Release preview проверка оплаты, автопродления и бесплатного входа через рекламу
  • Бесплатный вход перед подключением пользователь смотрит рекламный блок, после зачёта получает разрешение на старт VPN.

продажный сценарий

Оплата и автопродление

Покупка тарифа идёт через YooKassa. После успешного платежа webhook активирует подписку, а сохранённый способ оплаты используется для будущего автопродления после отдельного включения renewal-worker.

1

Выбор тарифа

Клиент запрашивает quote у backend, сумма и параметры тарифа считаются только сервером.

2

Оплата

Пользователь переходит на платёжную страницу провайдера; данные карты не попадают в Green VPN.

3

Активация

Backend сверяет платёж с YooKassa и активирует тариф только после подтверждения.
