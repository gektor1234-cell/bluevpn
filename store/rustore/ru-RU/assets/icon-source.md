# Icon source

The store icon was derived from
`android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` with the built-in
image generation tool, then downscaled to an opaque 512x512 RGB PNG.

Prompt summary: preserve the Green VPN white shield/key and green/cyan palette;
use an edge-to-edge opaque green background; no text, watermark, transparent
border, outer card, or extra symbols.
